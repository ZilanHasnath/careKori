# 🩺 careKori

> *Caregiver Hiring & Patient Progress Platform*

---

## 📌 Overview

**careKori** is a modern, full-stack, role-based platform designed to bridge the gap between patients, caregivers, and family members. It streamlines healthcare coordination by empowering patients to hire verified caregivers, enabling caregivers to log daily progress updates, offering family members real-time visibility through unique identifiers, and providing administrators with robust oversight tools.

## ✨ Core Features

| Portal / Module | Key Capabilities |
| --- | --- |
| 🧑‍⚕️ **Patient Portal** | Search & filter qualified caregivers, send hiring requests, link family members, and monitor daily health logs. |
| 🤝 **Caregiver Portal** | Manage incoming job requests, view patient history, and submit detailed daily progress updates. |
| 👨‍👩‍👧 **Family Member Portal** | Link to a patient profile using a unique ID for real-time tracking and health updates. |
| 🛡️ **Admin Dashboard** | Oversee user profiles, monitor global job statuses, and manage system administrators securely. |

## 🛠️ Technology Stack

* **Framework & Engine:** `Next.js 16 (App Router)` with `Turbopack`
* **UI & Styling:** `React`, `Tailwind CSS`, `TypeScript`
* **Deployment:** `Vercel`

## 📂 Project Architecture

```text
app/
├── admin/          # System oversight, admin management, profiles
├── auth/           # Login & multi-role registration flows
├── caregiver/      # Job requests, active roster, progress logging
├── familymember/   # Patient linking and health monitoring
└── patient/        # Caregiver search, request management, progress tracking

api/
├── admin/          # Administrative actions and data access
├── auth/           # Authentication handlers
├── caregiver/      # Job acceptance, history, and log updates
├── family/         # Patient verification and log retrieval
└── patient/        # Search filters, booking requests, and profiles

```

## ⚙️ Getting Started

### Prerequisites

Ensure you have **Node.js** and **npm** installed on your machine.

### Installation & Setup

```bash
# 1. Clone the repository
git clone https://github.com/ZilanHasnath/careKori.git

# 2. Navigate to the project directory
cd careKori

# 3. Install dependencies
npm install

# 4. Run the development server
npm run dev

```

> *Open [http://localhost:3000](http://localhost:3000) in your browser to view the application locally.*

```bash
# Build for production
npm run build

```
